Contains code for a model rockets avionics package. This includes flight-data logging (with stats such as altitude, speed, temprature, etc)
and automated parachute ejection. This was built for an ESP32-C3 microcontroller however it can be easily modified to fit other boards such
as Arduinos. Uses a GY-521(MPU-6050) IMU, BMP280 air-pressure/temperature sensor and an SD-card module.
